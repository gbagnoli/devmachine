# Jellyfin

Donbot opts into the official Jellyfin `latest` image, a rootful container with
the host data account's numeric UID/GID. No HTTP/discovery ports are published.
Caddy serves `https://video.<zone>/` and `https://media.<zone>/`, using the
environment's Cloudflare zone and the same explicit `--public-target` as Joplin.
Both names retain Jellyfin's native account authentication. Homer links to
`video.<zone>`. See [public ingress delivery](../caddy/README.md#public-services).

The caller reuses Arr's `files_path`, `music_path`, owner and group:

| Arr final destination on Donbot | Jellyfin library path |
| --- | --- |
| `/var/lib/data/media/files/library/tv` | `/media/tv` |
| `/var/lib/data/media/files/library/movies` | `/media/movies` |
| `/var/lib/data/syncthing/data/music` | `/media/music` |

All three mounts are read-only with shared SELinux labels. Downloads and Arr
configuration are not mounted. New media should retain Arr's shared data identity
and readable files/traversable directories. Apply never recursively changes media
ownership. Jellyfin configuration stays in `/var/lib/data/jellyfin/config`;
its artwork/transcode cache uses `/var/lib/data/jellyfin/cache`. These are
separate from the Caddy cache and Syncthing data. Repeat apply preserves native
users, libraries and preferences. No Jellyfin password is stored or generated by
Skillet; create native accounts and complete setup before public DNS activation.

In the initial Jellyfin wizard, add TV, Movies and Music using the container
paths above. Configure Caddy's actual bridge address under Networking → Known
Proxies before relying on forwarded client addresses or remote-access limits.
Caddy handles WebSocket upgrades and byte ranges through its normal reverse
proxy. CPU transcoding is supported; no GPU or device access is granted.

The optional [Caddy cache](../caddy/README.md#jellyfin-cache) handles anonymous
static web assets only. Artwork APIs, streams, tokens and authenticated responses
remain uncached. Native configuration backup/restore and public playback/client
acceptance remain in the [Donbot plan](../../../plan/DONBOT-MIGRATION.md).
